Can you recognize the source images? Magnitude describes the amplitude of each spatial frequency; phase describes how the components align, often with a strong influence on structure and position. Compare the inputs and results.

Calculation and display ＋

I′_c = Re{ IFFT2( |FFT2(A_c)| · exp(i · φ_c) ) }

For each output color c, choose a donor color d. Checked uses B_d phase; unchecked uses A_c phase. The second result reverses A and B with the same settings. Magnitude always comes from the original output color; pixel colors are not rearranged.

R, G, and B are processed independently and recombined. The forward FFT is unscaled; the inverse divides by 256 in each dimension (65,536 in total). Calculations use native frequency order, without fftshift.

Display = round(clamp(real part, 0, 255)). No absolute value or automatic contrast stretching is used. Values outside the display range are clipped. Phase is stored as zero at exactly zero magnitude.
