Each RGB channel is processed independently. Masks use native FFT indices with modular pairs M(u,v) = M(−u,−v). Analysis corrects floating-point conjugate errors; zero-magnitude phase is stored as zero. Only display values are clipped to 0–255 and truncated to integers. Reconstruction is not converted to an absolute value or individually contrast-normalized.

Disk radius = √[(u/N)² + (v/N)²]. Stripes select B in even bands of floor(|u|/width) or floor(|v|/width). Quadrant masks retain A phase on axes and Nyquist rows / columns.
