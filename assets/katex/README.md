# KaTeX 0.16.22

Vendored from the official `katex@0.16.22` npm package:
https://registry.npmjs.org/katex/-/katex-0.16.22.tgz

Only the minified browser renderer, CSS, fonts, and upstream MIT `LICENSE` are
included. No package installation, CDN connection, or build step is required.
Home and Documentation share `js/math.js` for rendering explicit math elements.
