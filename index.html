你還認得出原本的圖片嗎？ 振幅描述不同空間頻率的強弱；相位描述它們如何對齊，常對輪廓與位置有關鍵影響。試著比較上下兩排。

計算與顯示方式 ＋

I′ = Re{ IFFT2( |FFT2(A)| · exp(i · arg(FFT2(B))) ) }

R、G、B 分別運算後合併。正向 FFT 不縮放；反向每一維除以 256，總共除以 65,536。計算使用原始頻率排列，不做 fftshift。

顯示值 = round(clamp(實部, 0, 255))。不取絕對值、不自動拉伸對比。裁切會失去過暗或過亮的細節；上方百分比是超出範圍的 RGB 通道樣本比例。相位來源的振幅恰為零時，相位約定為 0。
