Gaussian Sharpening

Original + alpha × high-frequency response

Re(IFFT) → clamp
Calculation and display ＋

H_LPF = G(σ₁)
H_HPF = 1 − G(σ₁)
H_Sharp = 1 + alpha × [1 − G(σ₂)]

G(σ) = exp[−(u² + v²) / (2σ²)]. Each section has its own sigma. Original Fourier coefficients are multiplied by the corresponding Gaussian transfer function independently for R, G, and B, then inverse-transformed; the real part is used.

Both sigma controls use frequency-bin units on a 1000 × 1000 reference grid. For an N × N FFT, actual sigma is sigma × N / 1000. Both start at 30; alpha starts at 1.0.

LPF and sharpening: round(clamp(Re(IFFT), 0, 255)). HPF: round(clamp(Re(IFFT) + 128, 0, 255)). Raw values retain their signs. No absolute value or per-image normalization is used; display mapping does not change IFFT results. Sharpening has no +128 offset.

The FFT assumes periodic boundaries, so differences between opposite edges can generate edge responses. Display values outside 0–255 are clipped.
